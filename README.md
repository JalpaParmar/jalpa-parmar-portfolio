# Jalpa Parmar portfolio

Static GitHub Pages portfolio for a Technical Project Manager. The site is served from the repository root with relative paths and no build step.

## Projects

- **Delivery360** (`delivery360.html`): independent delivery and release health case study; four artifacts in `assets/documents/delivery360/`.
- **TriagePilot AI** (`opspilot.html`, `projects/opspilot/`): working browser prototype with human approval and case study; artifacts in `assets/documents/triagepilot/`.
- **ReviewPulse** (`reviewpulse.html`, `projects/reviewpulse/`): working static feedback dashboard and case study; artifacts in `assets/documents/reviewpulse/`.
- **SmartServe** (`product-case-study.html`): independent product management concept case study; four artifacts in `assets/documents/smartserve/`.

All project examples use synthetic data. Delivery360 and SmartServe are case studies rather than deployed applications. The existing CV PDF retains its older filename under `assets/documents/` and is linked from the homepage.

Preview locally with `python3 -m http.server 8000` from the repository root. GitHub Pages serves `main` from `/(root)` at `https://jalpaparmar.github.io/jalpa-parmar-portfolio/`.
